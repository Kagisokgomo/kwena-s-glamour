== Description ==

This nail Artist Theme is designed to give your website a strong first impression of your work as a nail artist. In the beauty center and fashion industry, it is essential to have a trendy and attention-grabbing website, which is why we offer this nail Theme. We have tailored this theme to build a strong foundation for your website and beauty business so that you can stay ahead in this highly competitive world. The design and quality are outstanding—you will be convinced of this once you try the demo. WP Theme provides you with various styles, including diverse layout designs and pre-designed data in the form of inner pages. You can customize this theme to achieve your website goal with no limitations. Its code-less tweaking options make the theme easy to use for those who have little to no coding knowledge but still want to design their website. Over a dozen pre-designed templates are available to give you enough choices. The email subscription form is added in advance, and if you want, you can. Another way to make it easier for your customers to find your business is by adding Google Maps to your website.

For Homepage Setup:
====================

1. Go to Dashboard >> Pages >> Add New, Create a new page and name it as "Home" then select the template "Custom Home Page" and publish it.

2. Go to Dashboard >> Settings >> Reading, Select the option of Static Page, now select the page you created to be the homepage.

For Social Icons:
=================

1. Go to Dashboard >> Appearance >> Customizer >> Theme Settings >> Social Icons, add social media urls and publish it.

For Slider:
============

1. Go to Dashboard >> Pages >> Add New, Create a new Page and name it, add the content, featured image (image size 350px x 350px) and publish the page. Repeat this step for other sliders.

2. Go to Dashboard >> Appearance >> Customizer >> Theme Settings >> Slider Settings, Click the checkbox of Show/Hide Slider, select the pages of the slider that you have created and publish it.

For Service Section:
====================

1. Go to Dashboard >> Posts >> Category, add new category for Service section, name it and publish it.

2. Go to Dashboard >> Posts >> Add New, Create a new Post and name it, assign the service category and publish the post. Repeat the step for other service posts.

3. Go to Customizer >> Theme Settings >> Service Section, add section title, add section text, select the category that you have created, you can also change the number of post to show & icons of services and publish it.

For About Section:
====================

1. Go to Dashboard >> Pages >> Add New, Create a new Page and name it, add the content, featured image and publish the page.

2. Go to Customizer >> Theme Settings >> About Section,  add section title, select the page that you have created and publish it.

For Footer Section:
====================

1. Go to Dashboard >> Appearance >> Widgets, here you can add widgets to the footer widgets areas, which can be seen in footer.

For Copyright Text:
====================

1. Go to Customizer >> Theme Settings >> Footer Text, add footer text here and it also have an option to show/hide back to top.
